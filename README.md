# Farmacia-marketplace-codigojava


## I - Introducción
Marketplace de una tienda de productos de parafarmacia (los medicamentos están prohibidos su venta por internet).  Esta aplicación se encargara de la parte del Backend.


## II - Diseño técnico breve
Se desarrollara íntegramente el backend bajo: 

- Lenguaje de programación:  Java 21 con Spring Boot 4.X.
- Arquitectura monolítica:  Determina cómo se despliega y empaqueta el sistema completo).  A futuro existirá una versión de micro-servicio.
- Arquitectura hexagonal: Determina como se organiza el código por dentro de esa aplicación se define las reglas de separación de la lógica de negocio (núcleo) de la tecnología exterior (bases de datos, formularios web, etc.).
- Motor de base de datos:  Oracle Database, PostgreSQL, MySQL (pendiente por determinar que dos motores eligiéremos).
- Tecnologías de contenedores: Docker para las Bases de datos y pendiente de evaluar si también la aplicación.
- Sistema de control del software: Git y Github.

 Aunque no corresponda tratar aquí la parte del Frontend, mencionamos que se desarrollara en Angular.
